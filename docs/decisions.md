# 결정 기록

형식: 날짜 · 결정 · 이유 · 대안

## 2026-09-13
- **엔진 직접 구현(PyTorch CUDA), 원논문 파라미터 그대로.** 이유: 정확도 우선, 브라우저 엔진들은 가지치기/속도 제약. 대안: fly-brain-bench(가지치기), webgpu-fly(가중치 변경) — 기각.
- **v630 → v783 3단계 검증.** 이유: 논문은 v630, 리포 기본값도 v630. 처음부터 v783에서 재현하면 불일치 원인을 못 가림.
- **몸은 FlyGym 2.1.0.** 이유: CT 기반 몸·겹눈·접촉·보행 컨트롤러 내장. 후각은 2.x에 없어 직접 계산.
- **뷰어는 영상 스트리밍부터.** 이유: 5주차까지 뇌 연결에 집중. Godot/WASM 뷰어는 P2.
- **파리 1마리.** 이유: 8GB GPU로 실시간 뇌 1개가 한계.
- **Brain Surgery를 P0.5로.** 이유: "스크립트가 아니라 커넥톰"임을 30초 안에 보여주는 방법. silencing은 마스크 한 줄이지만 동일 조건 재실행에 snapshot/restore가 필요해 1주차 엔진 설계에 포함.
- **silencing은 출력 시냅스만 0.** 이유: 원본 `model.py` 코드와 동일하게(README 문구와 다름).
